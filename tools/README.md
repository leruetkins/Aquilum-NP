# Репозиторий инструментов разработки и автоматизации (tools/)

Данная папка содержит автономные вспомогательные утилиты, скрипты автоматизации и тестовые раннеры для проекта Aquilum / Vibecodium.

## Структура папки

```text
tools/
├── gui_tester/                # Инструмент визуального тестирования и автоматизации GUI (Python + OpenCV)
│   ├── core.py                # Ядро: управление окнами, захват экрана, буфер обмена, поиск картинок, клики, diff
│   ├── cli.py                 # CLI интерфейс с поддержкой --json (для вызова агентами и людьми)
│   ├── templates/             # Эталонные изображения кнопок, иконок и элементов интерфейса
│   ├── screenshots/           # Скриншоты работы, дампы окон и отчеты о визуальных отличиях (diff)
│   ├── scenarios/             # Готовые сценарии тестирования пользовательских путей
│   ├── README.md              # Документация для разработчиков
│   └── AI_GUIDE.md            # Инструкция для нейросетей-агентов (AI) по автономному тестированию
└── (будущие инструменты...)
```

## Добавление новых инструментов

Каждый новый инструмент создается в отдельной подпапке `tools/<tool_name>/`:
1. Должен содержать `README.md` с описанием установки и запуска.
2. Если инструмент вызывается ИИ-агентами, рекомендуется предоставлять CLI с флагом `--json` и файл `AI_GUIDE.md`.
