# AGENTS.md (monorepo)

Правила для ИИ-исполнителей и людей. Читаются перед любой правкой.

- **`aquilum-gpui/`** (Vibecodium, Rust + GPUI) — обязательно прочитать `aquilum-gpui/AGENTS.md`.
  Главное правило: **новые компоненты не создаются**; используется существующий редактор,
  существующая полоса вкладок, существующие стили и иконки.
- **`tools/`** — инструменты автоматизации и тестирования для ИИ-агентов и разработчиков:
  - `tools/gui_tester/` — визуальное тестирование GUI (Python + OpenCV): запуск приложений,
    поиск кнопок по шаблонам картинок, клики, hover, скриншоты в буфер обмена (`CF_DIB`) и diff.
    Инструкция для ИИ: `tools/gui_tester/AI_GUIDE.md`.
- `aquilum-app/`, `operator-panel/` — правила, если появятся, лежат в их собственных каталогах.

Планы и постановки по рабочей области: `aquilum-gpui/TODO/multi-document-workspace-plan.md`,
`aquilum-gpui/TODO/workspace-4-panels-spec.md`.
